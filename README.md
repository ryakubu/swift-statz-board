# Swift Statz Board

Swift Statz Board is a backend + frontend project designed to manage and display user statistics efficiently. It integrates RESTful API endpoints with a React-based dashboard for data visualization.

## 🚀 Features
- REST API for handling user and post data
- React-based dashboard for visualization
- Jest test coverage for APIs and components
- GitHub Actions CI/CD pipeline
- AI-assisted development (tests, docs, and commits)
